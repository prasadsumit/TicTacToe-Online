#  TicTacToe Online

A real-time multiplayer TicTacToe game built using **React**, **Node.js**, and **WebSockets**. Challenge your friends or strangers and enjoy a smooth, interactive game experience right from your browser.

---

##  Features

-  **Real-time gameplay** using WebSockets
-  Smart turn-based logic
-  Lightweight and responsive UI with React
-  Room validation and game state management
-  WebSocket connection handling (join/leave/disconnect)

---

##  Tech Stack

### Frontend
- React
- Socket.IO Client

### Backend
- Node.js
- Express
- Socket.IO
- MongoDB 

Built with ❤️ using React, Node.js and Socket.IO.
